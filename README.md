## Swarm Architecture

5-agent NVIDIA NIM Swarm with async DAG execution:

```
Phase 1 (Parallel)          Phase 2 (Sequential)
-----------------           --------------------
  architect (70B)              reporter (70B)
  complex_coder (70B)              ^
  proof_writer (70B)             analyst
  analyst (70B)              (synthesizes all)
```

**Agents:**
- **architect** — System design, ASCII topology, API specs, DB schema, security model
- **complex_coder** — Production Python with type hints, tests, logging, argparse CLI
- **proof_writer** — Formal correctness proofs: termination, safety, liveness, concurrency
- **analyst** — Threat matrix with CRITICAL/HIGH/MEDIUM/LOW severity ratings
- **reporter** — Synthesis into aesthetic markdown with badges and deep links

## Proof Summary

The async DAG execution engine satisfies:
1. **Termination** — Completes in O(|V| + |E|) steps
2. **Safety** — Circular dependencies detected by topological sort
3. **Liveness** — Ready agents execute within O(1) scheduling rounds
4. **Bounded Concurrency** — Semaphore invariant: 0 <= active <= max_concurrent
5. **Compositionality** — Independent subgraphs satisfy properties locally => globally
