## Why Migrate to NVIDIA NIM?

| Factor | Groq Compound Mini | NVIDIA NIM Swarm |
|--------|-------------------|------------------|
| Throughput | ~450 tps | ~3100 tps (H100) |
| Tool Orchestration | Server-side (locked in) | Client-side (portable) |
| Model Lock-in | High (OpenAI-only pivot) | Low (any model) |
| Deprecation Risk | High (systematic purges) | Low (you control models) |
| Grammar Constraints | No (retry logic) | Yes (regex/BNF decode) |
| Async Parallelism | Serial | 16-agent DAG |

## API Compatibility Layer

### Groq (Before)
```python
from groq import Groq
client = Groq(api_key="gsk_...")

# Single call — server handles everything
response = client.chat.completions.create(
    model="groq/compound-mini",
    messages=[{
        "role": "user",
        "content": "Research quantum computing breakthroughs and write Python to simulate a qubit"
    }]
)
# Server internally: search → browse → code → synthesize → return
```

### NVIDIA NIM Swarm (After)
```python
import asyncio
from src.nvidia_swarm.swarm_main import run_swarm_task

# Parallel DAG — 3 agents work simultaneously
result = asyncio.run(run_swarm_task(
    task="Research quantum computing breakthroughs and write Python to simulate a qubit",
    lens_names=["researcher", "analyst", "coder"],
    context={
        "nvidia_api_key": "nvapi-...",
        "nvidia_base_url": "https://integrate.api.nvidia.com/v1",
    }
))
# Agent 1 (Researcher): web search + browse
# Agent 2 (Analyst): synthesize findings
# Agent 3 (Coder): write Python
# Orchestrator: merge results
```

### Step 2: Replace Single Call with Swarm
```python

# response = client.chat.completions.create(model="groq/compound-mini", ...)
```

### Step 3: Add Tool Orchestration
```python
# OLD: Tools executed server-side by Groq
# NEW: Tools executed client-side by your swarm

researcher = LensProfile(
    name="nvidia_researcher",
    agent_type="researcher",
    model="meta/llama-3.1-405b-instruct",
    tools=[
        {"name": "web_search", "description": "Search the web"},
        {"name": "web_open_url", "description": "Open a URL"},
        {"name": "ipython", "description": "Execute Python code"},
    ],
    grammar=r'\{\s*"tool"\s*:\s*"(web_search|web_open_url|ipython)"...',
)
```

## Cost Comparison

|----------|-------------------|-----------------|---------|
| 1M input tokens | $0.15 | ~$0.50 | -233% |
| 1M output tokens | $0.60 | ~$1.50 | -150% |

*Note: NVIDIA NIM is more expensive per-token but eliminates tool costs. For agentic workloads with many tool calls, total cost is often lower.*

## Fallback Strategy

```python
async def resilient_complete(prompt: str):
    """Try Groq → NVIDIA → Together → fail gracefully"""
    providers = [
        ("groq", groq_client, "openai/gpt-oss-120b"),
        ("nvidia", nvidia_client, "meta/llama-3.1-405b-instruct"),
        ("together", together_client, "meta-llama/Llama-3.3-70B-Instruct"),
    ]
    for name, client, model in providers:
        try:
            return await client.complete(prompt, model=model)
        except Exception as e:
            print(f"{name} failed: {e}")
            continue
    raise RuntimeError("All providers exhausted")
```
